# AI-Based Phishing Detection System

## Overview
The AI-Based Phishing Detection System is a machine learning-powered cybersecurity application designed to identify malicious phishing URLs and websites in real time. The project uses advanced machine learning algorithms and URL feature extraction techniques to classify websites as legitimate or phishing.

This project aims to enhance online security by protecting users from phishing attacks, fraudulent websites, and credential theft.

---

## Features
- Real-time phishing URL detection
- Machine learning-based prediction
- URL feature extraction
- User-friendly interface
- High prediction accuracy
- Explainable AI support
- Fast and secure detection system
- Dataset preprocessing and visualization

## Dataset
The dataset contains phishing and legitimate URLs with multiple extracted features such as:

- URL Length
- HTTPS Usage
- Presence of IP Address
- Number of Dots
- Prefix/Suffix Usage
- Domain Age
- edirection Count
- Special Characters
